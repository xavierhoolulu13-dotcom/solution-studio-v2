# Solution Studio v2 — Factory Console

**The machine room.** Operator console for the Factory software system. Market intel in, fireproof gates, build specs out.

## The flow

1. Add a market (the niche to evolve)
2. Teardown competitors: money model, customer engine, strengths, gaps
3. Draft product ideas from the gaps
4. Run the 7 fireproof gates — all pass → build spec
5. Ship through Boomerang

## Fireproof gates

1. The Take — honest assessment done
2. No fake data
3. Complement check — feeds the next X product
4. Boomerang ready — self-heal capable
5. $0 to run
6. Your tap
7. The pitch exists — selling job named

Static, localStorage, $0. Operator only — client-facing comes later.
